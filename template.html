Google 地圖

有 Google 金鑰：地圖、店家、街景、大眾運輸與機車路線都用 Google。清空＝改回開放地圖。

怎麼申請 Google 金鑰（約 10 分鐘）
  1. 打開 Google Maps Platform 開始使用，用 Google 帳號登入，照畫面建立專案、綁信用卡（每月免費額度內不收錢，綁卡是 Google 規定）。
  2. 啟用三個 API（點了按「啟用」）：Maps JavaScript API、Places API (New)、Routes API。
  3. 到 金鑰與憑證 點你的 API 金鑰 →「應用程式限制」選網站，加入 →「API 限制」勾上面三個 → 儲存。
  4. 複製金鑰（AIza 開頭）貼到上面，按「儲存並重新載入」，再按「檢查 Google 設定」。
  5. 選填：地圖管理 → 建立 Map ID（JavaScript、向量、勾傾斜和旋轉）→ 貼到 Map ID。導航時地圖才能轉向、傾斜。
  6. 建議：配額 每個 API 設每日上限，帳單設預算警示。
